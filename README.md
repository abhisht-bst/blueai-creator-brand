# BlueAI Creator Homepage: Version B Mock

Single-file mock of the futuristic creators homepage ("The AI You Own"), built for the Version B repositioning: BlueAI as an AI worker you own and deploy, with the creator program as its first asset.

## How to view

Open `index.html` in any browser. No build, no server, everything (styles, script, images) is embedded in the one file.

Reload the page to replay the intro.

## What's in the page

1. **Boot intro**: the agent core assembles from pixels (ported from the product's boot animation), introduces itself ("This is your AI worker." / "It exists to make you money."), then flies down and docks into the worker robot's chest. The robot wakes and the page reveals. Click anywhere to skip.
2. **Hero**: "Own an AI that works for you." with the worker robot running a laptop; completed tasks float up as toasts and credit the Earned pill.
3. **It earns while you sleep**: approval copy plus faint robot crew working in the background.
4. **Steps**: Apply, Get accepted, Deploy it, Collect ($30 every month via PayPal).
5. **Closer**: "Everyone will have one." with the fixed monthly amount.
6. **Outro**: "One worker, any machine you own" asset slots (PC live, home robots / robotaxis soon).

There is also a bottom-right dock with a time-aware line and a mini earnings counter that appears on scroll.

## Notes

- The demo numbers (per-task dollars, earned total) are illustrative; the honest fixed amount ($30/month) lives in the copy per the Aug 2026 design sync. The task-loop UI treatment is with the design team.
- Visuals are placeholder-grade: the robot and scene are hand-drawn SVG specs for the design team to redraw in brand style.
- Live preview also deployed at https://blueai-users.vercel.app (may lag this repo).
